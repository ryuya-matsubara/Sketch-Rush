# Sketch Rush

制限時間内に次々と絵を描き、最後にお題を当てるブラウザゲームです。自分で回答するモードと、同じ端末を他の人に渡して回答してもらうモードで遊べます。

## 遊び方

1. ホーム画面で「自分で回答」または「他の人が回答」を選びます。
2. 1枚あたりの制限時間と問題数を選び、「ゲームスタート」を押します。
3. 表示されたお題を制限時間内に、途中操作なしで連続して描きます。
4. シャッフルされた絵を見て、元のお題を回答します。
   - **自分で回答**：お題を入力して正誤を確認し、最後に記憶スコアと正答率を確認します。
   - **他の人が回答**：端末を他の人に渡し、何の絵か考えてもらいます。「回答を見る」で答えを表示し、「次へ」で次の絵へ進みます。自動採点はありません。
5. 終了画面の「ホームに戻る」で、最初のモード選択画面へ戻ります。

| モード | 1枚あたりの制限時間 | 問題数 |
| --- | --- | --- |
| 自分で回答 | 2秒・2.5秒・3秒 | 10問・15問・20問 |
| 他の人が回答 | 7秒・10秒・15秒 | 5問・7問・10問 |

## 特徴

- スマートフォンの指操作とPCのマウス操作に対応
- 選択した制限時間の経過時にCanvas画像を自動保存
- 描いた画像とお題をブラウザ内で紐付け
- 記憶テストは描画順から必ず並べ替えて出題
- 前後の空白、全角・半角スペース、英字の大文字・小文字を無視して判定
- 外部サーバーやデータベースを使わないフロントエンド完結型

## 起動方法

`index.html` をブラウザで開くだけで遊べます。GitHub Pagesを有効にした場合は、公開URLからスマートフォンでも遊べます。
