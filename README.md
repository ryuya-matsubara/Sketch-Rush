# Sketch Rush

3秒で絵を描く瞬発力と、自分が描いた絵を覚えている記憶力を試すブラウザゲームです。

## 遊び方

1. 「ゲームスタート」を押します。
2. 表示されたお題を3秒以内に描きます。
3. 10個のお題を、途中操作なしで連続して描きます。
4. シャッフルされた自分の絵を見て、元のお題を回答します。
5. 全10問の記憶スコアと正答率を確認します。

## 特徴

- スマートフォンの指操作とPCのマウス操作に対応
- 3秒経過時にCanvas画像を自動保存
- 描いた画像とお題をブラウザ内で紐付け
- 記憶テストは描画順から必ず並べ替えて出題
- 前後の空白、全角・半角スペース、英字の大文字・小文字を無視して判定
- 外部サーバーやデータベースを使わないフロントエンド完結型

## 起動方法

`index.html` をブラウザで開くだけで遊べます。GitHub Pagesを有効にした場合は、公開URLからスマートフォンでも遊べます。
